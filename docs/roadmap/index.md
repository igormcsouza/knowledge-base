# Roadmap: Day X Until Senior

A running log toward becoming a Senior Software Engineer, tracked as a competency matrix
rather than a single checklist — growth into a senior role is multi-dimensional (depth,
breadth, and impact all matter), and a matrix makes it easy to see which dimension needs
attention next.

!!! note "On tooling"
    This starts as a plain markdown table — no dedicated competency-matrix plugin needed
    yet. If the table outgrows this format (e.g. wanting per-skill history or filtering),
    it's worth revisiting a dedicated MkDocs plugin then, not before.
